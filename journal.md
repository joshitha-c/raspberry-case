### Journal0:
i measured every port on the Raspberry pi by downloading its step file and checking each connector size and position one by one. ## hrs spent: 1.5
# date: 3/11
### Journal1:
i designed the case for my Raspberry Pi zero project in fusion 360.the base is 70 mm×35 mm×10 mm, which leaves about 2.5 mm of wall around the 65 mm×30 mm board. inside the base I added four mounting posts, 5mm across,each with a 2.4 mm locating pin.the pins line up with the board mounting holes, so the pi sits in place without screws.
